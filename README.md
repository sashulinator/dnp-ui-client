# DNP

## Библиотеки

### Monaco

Изначально представляет собой редактор кода на ванильном js.
Имплементация состоит из 3х библиотек

- monaco-editor - сам редактор
- @monaco-editor/react - Обертка + загузчик для редактора
- vite-plugin-monaco-editor-esm - билдит monaco в dist и добавляет в index.html скрипт для подгрузки языков
